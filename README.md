# MiCore VPN for Android

<img src="https://api.micore.space/site/icon-512.png" width="96" align="right" alt="MiCore VPN icon">

MiCore VPN is a free Android VPN app with its own servers and its own client built on the Xray core.

- **Speed:** servers are used only by MiCore customers, without overload.
- **Security:** modern encryption with VLESS Reality, XHTTP and Hysteria2. No history of visited sites is kept.
- **No drop-outs:** reconnects when you switch between Wi-Fi and mobile data and switches to a live server of the same subscription if the current one stops responding.
- One-tap connection and the fastest server in one tap; choose which apps go through the VPN; kill switch, custom DNS, local network bypass, IPv6.
- Works with other subscriptions too: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, SOCKS and HTTP links; base64, Xray JSON, sing-box and Clash subscriptions; QR codes and links from other VPN apps.
- In-app updates, 40 languages, dark theme.

**Plans:** 72-hour free trial, then from $3 per month for up to 2 devices (crypto, Telegram Stars or SBP). Bring a friend: you both get 7 extra days after the friend's first payment. iPhone, iPad, Windows and macOS are supported via the Happ app with the same subscription. Subscription and support: Telegram bot [@MiCore_VPN_bot](https://t.me/MiCore_VPN_bot).
